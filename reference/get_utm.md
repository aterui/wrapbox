# Return UTM zone (EPSG code) based on geographic coordinates

Return UTM zone (EPSG code) based on geographic coordinates

## Usage

``` r
get_utm(x, y)
```

## Arguments

- x:

  Numeric scalar. Longitude coordinate.

- y:

  Numeric scalar. Latitude coordinate.
