# Package index

## All functions

- [`arc2d8()`](https://aterui.github.io/wrapbox/reference/arc2d8.md) :
  Convert ArcGIS flow direction to D8 flow direction
- [`flow2grid()`](https://aterui.github.io/wrapbox/reference/flow2grid.md)
  : Convert flow accumulation raster to stream grid
- [`get_key()`](https://aterui.github.io/wrapbox/reference/get_key.md) :
  Return file name keys for MERIT Hydro rasters
- [`get_utm()`](https://aterui.github.io/wrapbox/reference/get_utm.md) :
  Return UTM zone (EPSG code) based on geographic coordinates
- [`grid2stream()`](https://aterui.github.io/wrapbox/reference/grid2stream.md)
  : Convert stream grid to vector stream
- [`point2utm()`](https://aterui.github.io/wrapbox/reference/point2utm.md)
  : Return UTM zone (EPSG code) based on a point layer
- [`rast2poly()`](https://aterui.github.io/wrapbox/reference/rast2poly.md)
  : Convert raster to polygon(s)
- [`wsd_nested()`](https://aterui.github.io/wrapbox/reference/wsd_nested.md)
  : Delineate nested watersheds
- [`wsd_unnested()`](https://aterui.github.io/wrapbox/reference/wsd_unnested.md)
  : Delineate unnested watersheds
